Produces a list of all unique sums of four squares for a nonnegative integer.  The vast majority of the Rust code was generated by Copilot.


The command line is: 

    cargo run -- <n> <output limit> <number of output columns>

    - <n> is the nonnegative integer
    
    - <output limit> is the maximum number of unique sums for n that will be allowed
    
        - if the number of unique sums is greater than the output limit, there will be no output

    - <number of output columns> is the number of columns that the output will be displayed

For example: 

    cargo run -- 500 100 4 
    
produces:

[0, 0, 4, 22], [0, 0, 10, 20], [0, 6, 8, 20], [0, 10, 12, 16],
[1, 3, 7, 21], [1, 7, 15, 15], [3, 3, 11, 19], [3, 5, 5, 21],
[3, 7, 9, 19], [3, 9, 11, 17], [4, 4, 12, 18], [4, 12, 12, 14],
[5, 5, 15, 15], [5, 9, 13, 15], [6, 8, 12, 16], [7, 9, 9, 17],
[9, 9, 13, 13]

      cargo run -- 500 10 4 
      
produces:
            
n = 500, unique unordered nonnegative solutions: 17, the limit is 10
